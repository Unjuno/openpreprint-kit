## セキュリティ上の境界

存在時刻の証明と一般公開時刻の証明は異なる。Git コミット日時および単なる GitHub イベント日時を独立した暗号学的証拠として扱わない。時刻認証局の証拠は、原理的に「その内容が指定時刻以前に存在していたこと」を支持するものであり、一般公開や著作者資格を単独では証明しない。
