1. 各論文の対象SHA・ファイル一覧・各指紋を確認し、まず独立コピーのSHA-256をマニフェストと照合する。
2. 本文の著作権、CC BY-4.0表示、引用、第三者素材、著者表示について、承認/不承認と理由を記す。内容の科学的妥当性も確認する場合は、その範囲を別に明記する。
3. 研究データ・分析コードの由来、各ライセンス、個別公開同意、COI、個人情報・再識別リスク、秘密鍵や患者原本の混入を確認する。第2候補は全資産が現在非公開指定 (`public_confirmed=false`) なので、人間の権利確認と所有者の明示承認なしに公開指定へ変更しない。
4. 質問・回答・指摘・訂正案と、最終判定を記録する。承認できない項目は保留または不承認とし、空欄を成功扱いしない。

6. 署名または同等の本人確認可能な記録、実施日時、対象commit/ファイル指紋、利益相反申告、連絡方法を所有者へ返す。公開Issueには個人情報や機微なCOIを載せず、公開可能な要約・証拠指紋だけを残す。
