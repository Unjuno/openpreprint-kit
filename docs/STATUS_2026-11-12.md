# Completion work — 2026-11-12

**No production v1.0 declaration.** Existing G0–G7 gates are unchanged.

## Actual work and evidence boundaries

1. **Reproduced a real template-use defect:** changing the live paper title made
   the kit's validator unit test fail because it copied the author's metadata
   and searched for a template placeholder. The tests now own their fixtures.
   A regression runs the validator suite inside a copied repository with v2
   author metadata. This is a prerequisite for publishing real paper repos.
2. **Owner publication pilot:** `scripts/pilot.py` connects the existing toolkit
   into one explicit synthetic-only 2-repository/4-release operation. The default
   is a no-I/O plan; the mutation flag is explicit. Local integration tests use
   real OpenSSL TSA signatures, PDF/data packages and archive recovery, but
   **GitHub HTTP/CLI effects are mocked**. No actual public Release is claimed
   from those tests. See `OPERATIONAL_PILOT.md`.
3. **Real external-storage roundtrip:** the two earlier public-FreeTSA synthetic
   evidence ZIPs were uploaded to private Google Drive files, fetched again,
   SHA-256 checked, restored without GitHub/network, and reverified with OpenSSL
   3.5.5 under the separately pinned CA and retained signed, currently unexpired
   CRL. No fresh CRL distribution check was made. Sharing remained disabled.
   This proves one private cloud roundtrip, **not** independent custodial control,
   future retention, public availability, clinical correctness or real research.

## Explicit external blocker

The connected GitHub action surface has no repository creation or administration
write action. Browser access is read-only; no GitHub-authenticated TinyFish
profile and no remote desktop device were available. That does **not** authorize
bypassing access controls. The owner's native authenticated `gh` execution (or
an explicitly granted suitable connection) is required for the real pilot.
No token, password or private key should be sent to the assistant.

Still open: actual immutable Releases, separately operated witnesses and archive
custodians, genuine author disclosure approval, human scholarly process,
independent security/privacy review and tested long-term evidence renewal.
