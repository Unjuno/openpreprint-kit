# G4 owner-route technical observation evidence

**Status:** Technical observation records are generated and cryptographically verified for the four formal target releases. Formal G4 remains **PARTIAL** until the owner reviews and explicitly accepts this evidence in Issue #5.

## Scope and signer

Codex ran the repository's `scripts/observation.py record` command on the owner-managed Windows 11 computer on 2026-11-28 UTC / 2026-11-29 JST. The tool fetched the public Release assets using anonymous HTTPS (no Authorization header), checked the original Release manifest and RFC 3161 proof, and signed an observation statement for each target. A new RFC 3161 token was requested for each signed statement. The four observation directories include the exact public bundle, statement, Ed25519 signature, observation TSQ, and observation TSR.

The signing key was generated by this automation as a temporary technical witness key. It is **not a human signature**, does not identify the owner, and does not establish an independent witness. The expected public-key fingerprint was checked against the included public key on the same computer; it was not conveyed through an independent out-of-band channel. Record `independence=UNPROVEN` and do not describe this as independent review or external observation. The private key stayed outside the repository under a local ACL restricted to the signed-in user and SYSTEM. Only the public key is included here.

The observation statement asserts retrieval of the listed bytes during a self-reported interval. It does not claim first-publication time, authorship, honesty of an independent witness, scientific correctness, or editorial acceptance. TSA `accuracy` was absent, so time precision is unknown.
