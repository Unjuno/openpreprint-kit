# 論文ファイル

完成したPDFを `paper/paper.pdf` に追加してください。必要に応じて `paper/source/` に
LaTeX原稿・図表を保存できます。実際の著者・概要・版・論文ライセンスは `preprint.yaml` に設定します。

論文・図表・データの利用条件は、ツール本体のMITライセンスと別に指定してください。
このテンプレートには実論文は含みません。テスト用の簡易PDFは一時ディレクトリにのみ生成されます。

公開は `scripts/validate.py --strict` と時刻証明の設定を済ませてから、手動ワークフローで行います。
詳しくはルートREADMEと `docs/TIMESTAMPS.md` を参照してください。
