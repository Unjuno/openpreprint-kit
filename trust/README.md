# Trust material / 信頼設定

このディレクトリに置くのは **公開CA証明書と公開CRLだけ**です。
署名用秘密鍵、APIトークン、パスワードをコミットしないでください。

1. 利用するTSAの運用方針、時刻精度、SHA-256・nonce・HTTPS対応、料金・制限を確認する。
2. CA証明書を独立した信頼できる経路で確認し、`tsa-ca.pem` に保存する。
3. 信頼するPEMファイル全体のSHA-256を計算し、独立に確認した値と照合する。
4. 署名者からルートまでのCRLをPEM形式で連結し `tsa-crls.pem` に保存する。
5. ルートの `timestamp-policy.example.json` を `timestamp-policy.json` にコピーし、
   URL、CAファイルのハッシュ、CRLファイル、TSAの実際のpolicy OIDを設定する。

同じダウンロード元からCAとハッシュを取得しただけでは、そのCAの独立確認にはなりません。
証明対象の論文に付属するpolicyを無条件に採用しないでください。

検証は現在有効なCRLを要求します。期限切れ・取得不能・失効・証明書期限切れの場合は
成功扱いにせず停止します。CRLは検証のたびに更新可能な外部検証資料です。
秘密鍵がないのは欠落ではありません。署名するのは外部TSAです。
